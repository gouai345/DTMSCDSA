# Data
The data is from [GATECDA](https://github.com/yjslzx/GATECDA.git).
## Dataset Information

The `DTMSCDSA_code/data/` directory contains the constructed dataset and processed matrices used in this study.

- `a.csv`: circRNA-drug sensitivity association matrix used as model input, with 271 circRNAs and 218 drugs.
- `association.csv`: association matrix with row and column indices.
- `GSS.csv`: circRNA sequence similarity matrix.
- `DSS.csv`: drug structure similarity matrix.
- `gene_seq_sim.csv`: indexed version of the sequence similarity matrix.
- `drug_str_sim.csv`: indexed version of the drug structure similarity matrix.
- `circRNAs Feature.csv`: learned circRNA feature representations generated by DTMSCDSA.
- `drug Feature.csv`: learned drug feature representations generated by DTMSCDSA.

## Methodology

The DTMSCDSA workflow includes the following steps:

1. The circRNA-drug sensitivity association matrix is loaded from `a.csv`.
2. The circRNA sequence similarity matrix (`GSS.csv`) and drug structure similarity matrix (`DSS.csv`) are loaded as prior similarity networks.
3. A dynamic topology generation module is used to update neighborhood relationships and generate multi-layer topological representations.
4. A multi-scale spatial perception module is used to fuse multi-layer circRNA and drug features.
5. The learned circRNA and drug representations are concatenated and used for final association prediction with XGBoost.
6. Model performance is evaluated using AUC, AUPR, F1-score, precision, recall, and accuracy.
